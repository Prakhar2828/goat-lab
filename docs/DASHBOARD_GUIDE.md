# GOAT Lab Dashboard Guide

## What GOAT Lab is

GOAT Lab is an interactive Michael Jordan vs. LeBron James comparison. It separates the evidence from the value choices used to combine that evidence.

It is not an objective GOAT detector. The published result is one declared setup, and the simulator shows how different priorities can change the answer.

## Home

The Home page separates two findings:

1. **Published default result:** LeBron 89.259, Jordan 89.144, a 0.115-point difference.
2. **Stress-test result:** LeBron led 60.1% of 250,000 alternative within-section priority setups.

The 60.1% figure is not an objective probability that LeBron is the GOAT. It is the share of tested setups in which LeBron's score was higher.

## Career curves

Each point represents one season or playoff run. The 0–100 value is built from era-relative, reliability-adjusted metric families. The cumulative chart adds only value above 50.

## Peak, prime, and longevity

- **Peak:** best one or several seasons.
- **Prime:** best uninterrupted multi-year stretch.
- **Longevity:** accumulated career value above historical thresholds.

Calendar gaps break consecutive windows.

## Playoffs and opponent quality

The first chart shows playoff season value. The second compares actual series outcomes with a model's pre-series win probability.

`Overperformance = actual result − expected win probability`

This is team context, not proof that one player caused the complete result.

## Team and winning context

This page summarizes average playoff-series overperformance on a 0–100 display scale. It intentionally does not reduce championships to a rings count.

## Skill profile

The bars are league-relative standard scores. Zero is approximately league average. Positive values are above average. This page shows how value was created across scoring, playmaking, rebounding, box defense, and team impact.

## Cultural and broader impact

This category considers attention, commercial influence, social and philanthropic evidence, and influence on basketball culture. Because modern digital records favor LeBron's era, the dashboard shows sensitivity rather than treating the result as settled.

## Debate explorer

Each popular argument is broken into:

- why people believe it;
- the strongest counterargument;
- what analysis is required;
- the v1 verdict;
- confidence;
- the best page to explore next.

A verdict describes what v1 supports, not what every reasonable GOAT philosophy must conclude.

## Weight simulator

The model has three section totals that always remain fixed:

- Career performance: 50%
- Basketball value: 40%
- Broader influence: 10%

The sliders are relative priorities inside a section. GOAT Lab automatically normalizes them, so the effective model weight always totals 100%.

The presets are examples, not official answers. The result updates immediately and does not alter the published default result.

## Methodology

The Methodology page begins with a five-step plain-language overview and then provides expandable technical documentation covering data, era adjustment, reliability shrinkage, category construction, scaling, weights, simulations, limitations, and reproducibility.
