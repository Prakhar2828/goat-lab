# Product feature specification

## Landing page

- Concise research question
- Frozen data cutoff
- Current result under balanced weights
- Category comparison chart
- Three immediate answers: peak, career value, and broader impact
- Evidence-coverage warning

## Career curves

- Toggle regular season/playoffs
- Career-year and chronological-season views
- Season-value line
- Cumulative value line
- Threshold shading
- Hover details with raw and relative metrics
- Retirement/injury annotation layer

## Peak, prime, longevity

- Best 1/3/5/7/10 windows
- Consecutive and nonconsecutive windows
- Active-season versus calendar-span longevity
- Value above average/All-Star/All-NBA thresholds
- Bootstrap intervals

## Scoring and creation

- Points per 75 versus relative TS scatter
- Scoring load
- Playoff scoring change
- Assist/creation and turnover cost
- Shot-profile views where comparable
- Era-relative percentile table

## Defense

- Box, awards, on/off, lineup, and film tabs
- Metric coverage by season
- Assignment versatility matrix
- Film annotation distribution
- Coder agreement
- Modern-only data warning

## Playoffs

- Every run and every series
- Opponent strength
- Expected win probability
- Upset credit/favorite-loss cost
- Elimination and comeback samples
- Finals as one round, not the only round

## Team context

- Teammate-quality definitions toggle
- Rotation availability
- Coach and roster continuity
- Team performance without player
- Star versus support decomposition
- Expected title probability by season

## Cultural impact

- Attention, commercial, social, and influence tabs
- Overlapping-period and legacy modes
- Inflation-adjusted financial evidence
- Verified-impact ledger
- Source and confidence attached to every event

## Argument explorer

- Search and filters
- Strongest pro and con version
- Evidence charts linked to each argument
- Verdict and confidence
- Source list

## Weight simulator

- Preset philosophies
- Individual category sliders
- Live winner and margin
- Value-system explanation
- Shareable URL/query state in a future React version
- Random-weight win rates
- Decision boundary charts

## Methodology

- Formula glossary
- Metric registry
- Data coverage heatmap
- Model reports
- Missingness rules
- Limitations
- Downloadable processed evidence
